# CampusCare Prototype UI
Functional front-end prototype for the requested CampusCare design.

## Included screens
- Landing page
- Sign-in page
- Login page
- Dashboard
- Book Appointment
- Appointments
- Profile

## Tech
HTML + CSS + JavaScript only.

## Functional
- Page navigation
- Sign-in/login flow
- Password show/hide
- Appointment creation
- Appointment list
- Cancellation confirmation
- Profile editing
- Logout confirmation
- Toast feedback
- Responsive layout/mobile sidebar

## Run
Open `index.html` in a browser. For development, VS Code Live Server is recommended.

The data is currently local JavaScript demo data. Replace the form/state operations with `fetch()` calls when connecting the existing REST API.
